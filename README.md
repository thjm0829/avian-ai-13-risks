# 13. 위험요소 및 대응방안

> **작성 상태:** 세부 내용 작성 완료  
> **작성 기준일:** 2026년 8월 27일  
> **핵심 전제:** 본 시스템은 고병원성 조류인플루엔자를 확진하거나 법정 방역조치를 자동 결정하는 장비가 아니다. 분변 기반 반복 신속항원검사와 자동재검으로 공식검사가 필요한 농장을 선별하는 예찰보조 시스템이므로, 기술성능뿐 아니라 경보의 과신·현장 방역·데이터·규제·공공계약 위험을 함께 관리한다.

## 핵심 결론

본 사업의 가장 큰 위험은 장치가 고장나는 것만이 아니라 다음 세 가지다.

1. 초기 감염 또는 대표성 없는 시료에서 항원신호를 포착하지 못해 잘못된 안도감을 주는 위험
2. 분변 시료 편차·검사 방해요인·교차오염으로 잘못된 결과를 만드는 위험
3. 검증되지 않은 결과가 농가·지자체·방역기관의 공식 판단처럼 사용되는 위험

따라서 위험관리는 다음 순서로 수행한다.

> **위험 식별 → 원인·영향 분석 → 예방통제 설계 → 시험으로 통제효과 확인 → 잔여위험 평가 → Gate 통과·수정·중단 결정**

위험을 완전히 제거했다고 전제하지 않는다. 통제 후에도 남는 잔여위험과 불확실성을 사용자·수요기관·전문기관에 공개하고, 핵심 가설이 성립하지 않으면 일정이나 제품역할을 축소한다.

### 위험등급 운영원칙

위험등급은 사업 내부 관리도구이며 법정 제품분류나 허가심사를 대체하지 않는다. 구체적인 발생가능성과 수치기준은 [6. 기술 검증 및 실증](https://github.com/thjm0829/avian-ai-06-validation)의 시험결과를 확보한 뒤 확정한다.

| 등급 | 의미 | 관리원칙 |
|---|---|---|
| Critical | 동물방역·생물안전·법적 책임에 중대한 영향을 줄 수 있음 | 통제효과 확인 전 다음 Gate 진입 금지 |
| High | 현장운영·검사품질·계약지속성을 크게 훼손할 수 있음 | 책임자·완료기한·시험계획을 지정 |
| Medium | 반복 발생 시 비용·사용성·데이터품질을 저하시킬 수 있음 | KPI와 추세를 정기 모니터링 |
| Low | 영향이 제한적이며 표준절차로 복구 가능 | 이력 기록 후 주기 검토 |

생물안전, 위음성, 규제와 데이터 유출 위험은 발생가능성이 낮아도 영향도가 크면 낮은 등급으로 자동 하향하지 않는다.

## 13.1 낮은 초기 항원 신호

### 1. 위험 정의

신속항원검사는 현장에서 빠르게 사용할 수 있지만 낮은 바이러스 농도에서는 민감도가 제한될 수 있다. WOAH 진단자료는 항원검사를 초기 현장 선별수단으로 다루며, 음성 항원검사만으로 감염을 배제하지 않도록 안내한다. 상용 AIV 신속검사 평가에서도 바이러스 농도가 낮아질수록 진단민감도가 저하되는 양상이 확인됐다.

본 사업은 임상증상이 뚜렷한 개체를 직접 채취하는 방식이 아니라 계분벨트의 통합 분변시료를 검사하므로 다음 위험을 별도로 검증해야 한다.

- 감염 초기의 낮은 항원농도
- 개체·축종·바이러스 유형에 따른 배출량 차이
- 시간대별·간헐적 분변 배출
- 감염개체 분변이 다수 정상분변에 희석되는 현상
- Sampling Point가 감염개체의 분변을 포함하지 못하는 현상
- 채취 후 시간·온도·수분상태에 따른 항원신호 저하
- 전처리·희석으로 검출한계 아래로 내려가는 현상
- 키트·Lot별 분석민감도 차이

### 2. 주요 영향

- 실제 위험농장을 Negative로 기록
- 공식검사 요청과 이동통제 검토 지연
- 농가와 지자체가 음성결과를 안전확인으로 과신
- 시계열 기준선이 잘못 형성
- 시스템 신뢰도와 공공실증 중단
- 제품책임·계약분쟁 발생

C선이 정상적으로 나타났다는 사실은 키트의 유효한 흐름을 보여줄 뿐, Sampling Point가 농장을 대표했거나 충분한 항원이 포함됐음을 보증하지 않는다.

### 3. 예방·완화 통제

1. Negative를 감염 부재의 확정결과로 표현하지 않는다.
2. 동일 농장의 반복검사와 변화추세를 기본으로 사용한다.
3. Uncertain·약한 신호·위험보조정보 발생 시 자동재검한다.
4. 농장 신고·폐사·산란·사료·음수 변화가 있으면 장치 음성과 무관하게 기존 공식절차를 따른다.
5. 전문기관 시험에서 장치결과를 RT-qPCR 등 기준검사와 Pairing한다.
6. Ct 또는 바이러스량 구간별 장치 검출률을 분리해 분석한다.
7. 시료량·희석비·침전시간·상층액 위치의 회수율을 비교한다.
8. 한 Sampling Point의 대표범위를 실증 전 확정하지 않는다.
9. Multi-point는 기본제품 안정화 후 독립 시료·독립 검사로 비교한다.
10. 검사빈도는 Risk-based Adaptive Testing 원칙 아래 실증과 방역기관 협의로 결정한다.

### 4. 모니터링 지표

| 지표 | 확인목적 |
|---|---|
| 기준검사 양성 대비 장치 양성·음성·Invalid | 위음성 위험 확인 |
| Ct·바이러스량 구간별 검출률 | 낮은 농도 성능 확인 |
| 반복검사 일치도 | 간헐적 신호와 재현성 확인 |
| 지점·시간대별 결과차이 | Sampling 대표성 확인 |
| Composite 전후 회수율 | 희석·혼합 영향 확인 |
| 경보 선행시간 | 반복검사가 추가정보를 제공하는지 확인 |
| 공식검사 우선순위 적중도 | 현장 의사결정 지원성 확인 |

### 5. 수정·중단조건

- 공식 양성시료에서 장치 위음성이 반복되고 보완 가능한 Sampling·전처리 조건을 찾지 못한 경우
- 반복검사와 시계열 분석이 단일검사보다 우선순위 판단에 추가정보를 주지 못하는 경우
- Sampling Point 대표성 변동이 커 비교 가능한 농장 기준선을 만들 수 없는 경우
- 공식검사보다 의미 있는 선행정보를 확보하지 못하는 경우

이 경우 제품역할을 자동 시료관리·검사기록·키트 판독품질관리로 축소한다.

## 13.2 분변 시료 편차와 검사 방해요인

### 1. 용어와 범위

본 장치의 현장검사는 신속항원키트를 사용하므로 기존 목차의 PCR 저해물질이라는 표현을 사용하지 않는다. 분변의 고형물·점도·점액·색·pH·수분과 화학물질이 항원 추출, Membrane Flow, C선·T선 발현과 영상판독을 방해하는 위험을 **분변 시료 편차와 검사 방해요인**으로 정의한다.

PCR 저해는 전문기관이 동일 시료를 RT-qPCR로 비교할 때 발생할 수 있는 별도 실험실 변수다. 장치의 신속항원 결과와 기준검사 결과가 불일치할 때 장치오류와 기준검사 시료·추출 문제를 구분하기 위해 기록한다.

### 2. 주요 변동요인

| 구분 | 위험요인 |
|---|---|
| 농장 | 축종, 일령, 사료, 수분섭취, 질병·약품, 계사환경 |
| 시료 | 수분, 고형물, 요산, 점액, 색, pH, 이물질 |
| 채취 | 벨트속도, 분변두께, 채취위치, Sampling Timing |
| 보관 | 채취 후 경과시간, 온도, 건조, 동결·해동 |
| 전처리 | 시료량, 완충액량, 혼합강도, 침전시간, 필터 |
| 분주 | 상층액 흡입높이, 고형물 혼입, 분주량 |
| 키트 | 허용검체, 반응시간, 보관온도, Lot |
| 영상 | 배경색, 번짐, C선 약화, 외부광, 판독시간 |

분변 기반 신속검사 연구에서도 높은 밀도, 점액, 색과 pH가 RDT 반응을 방해할 수 있음이 보고됐다. 이를 본 제품의 확정성능으로 전용하지 않고, 실제 사용할 키트와 농장시료로 재검증한다.

### 3. 예방·완화 통제

- Sampling Event마다 위치·시간·벨트상태와 시료 QC를 기록
- 허용 시료량·수분등급·이물질 기준 설정
- 시료량 대비 완충액량을 고정하고 과도한 희석을 방지
- 혼합·침전·상층액 흡입높이를 기계적으로 반복 가능하게 설계
- 고형물 Carry-over와 Membrane Flow 실패를 별도 오류로 기록
- 키트별 허용검체·희석·반응시간을 Kit Profile로 관리
- 농장·축종·계절·Lot별 Matrix Blank와 Spike Recovery 시험
- 동일 시료의 수동분주·자동분주 결과 비교
- 필요 시 필터·원심·추가 전처리를 후보로 검증하되 현장복잡성과 비용을 함께 평가
- 실패·Invalid·Uncertain 결과를 분석에서 제외하지 않고 원인별 기록

### 4. 시험설계

| 시험 | 비교조건 | 산출물 |
|---|---|---|
| 시료편차 시험 | 수분·고형물·시간대·농장 | 유효검사율·신호변동 |
| 희석비 시험 | 시료·완충액 비율 | 회수율·C선·T선 신호·Invalid |
| 혼합·침전 시험 | 시간·강도·흡입높이 | 고형물 혼입·분주성공 |
| Matrix Spike 시험 | 음성분변+안전한 표준물질 | 방해율·회수율 |
| 수동·자동 비교 | 동일 시료·동일 Lot | 판독일치·T/C 변동 |
| Lot 비교 | 복수 제조 Lot | Lot 간 편차 |
| 기준검사 비교 | 장치시료와 전문기관 시료 | Paired Result·불일치 원인 |

### 5. 수정·중단조건

- 전처리 조건을 조정해도 유효검사율과 신호반복성이 현장사용에 부적합한 경우
- 고형물·색·점도 영향을 QC로 탐지하지 못하고 위양성·위음성으로 처리되는 경우
- 키트 IFU의 허용검체와 실제 분변 Composite Sample의 사용이 양립하지 않는 경우
- 현장 전처리가 지나치게 복잡해 자동화·원가·생물안전 목표를 훼손하는 경우

## 13.3 교차오염

### 1. 위험 정의

교차오염은 이전 시료의 항원이나 검체가 다음 검사에 Carry-over되어 위양성을 만들거나, 장치·작업자·농장환경에 검체를 확산시키는 위험이다. 실제 감염성 AIV 시료는 승인된 전문기관과 적절한 생물안전시설의 절차 안에서만 취급한다.

주요 오염경로는 다음과 같다.

- 다회용 Scraper·튜브·펌프·밸브에 검체 잔류
- 카트리지 외부 오염과 장착부 접촉
- 혼합·분주 중 튐·에어로졸·누액
- Dropper·Tip·Cassette의 잘못된 재사용
- 양성 시료 취급 후 폐기물·장갑·도구를 통한 전파
- 장치 내부 표면과 문손잡이·터치패널 오염
- 폐기백 파손과 임시보관 중 누출

### 2. 설계 통제

> **검체에 닿는 것은 일회용, 움직이고 읽고 계산하는 것은 다회용으로 구성한다.**

- Sampling Cup·Insert, Composite Cartridge, Tip, Cassette와 폐기 Liner 일회용화
- 검체가 다회용 펌프·튜브·밸브를 통과하지 않는 구조
- Wet Zone과 Dry Zone의 물리적 분리
- 밀폐 카트리지 외부혼합 방식
- Cartridge Presence Sensor와 Door Interlock
- 누액감지 후 모터정지·안전복귀
- 오염 가능 부품의 공구 없는 교체와 이중포장
- 일방향 작업동선과 청결·오염구역 표시
- 시료·키트·폐기물의 Barcode·Lot·시간 추적

### 3. 검증·운영 통제

- 고농도 안전 모사시료 후 음성 Blank Carry-over 시험
- 연속검사 순서별 오염률 확인
- 카트리지 외부와 Dry Zone 표면 Swab 점검
- 누액·파손·오장착 Fault Injection 시험
- 오염사고 시 장치격리·운영중지·소독·보고 SOP
- 농장별 폐기물 밀폐·임시보관·인계 절차
- 작업자 보호구, 손위생, 교체순서와 교육기록
- 소독제의 재질 적합성·키트간섭 여부 확인
- 실증 중 감염의심 상황 발생 시 농장 방역기관 지시 우선

### 4. 모니터링 지표

| 지표 | 관리목적 |
|---|---|
| Blank 양성·의심률 | Carry-over 탐지 |
| 장치 내부 누액건수 | 봉쇄성능 확인 |
| 일회용품 오장착률 | 작업오류 확인 |
| 폐기물 밀폐 실패 | 현장 생물안전 확인 |
| 표면 Swab 이상 | Dry Zone 오염 확인 |
| 오염사고 복구시간 | SOP 실효성 확인 |
| 작업자 교육 이수율 | 인적 통제 확인 |

### 5. 즉시 중단조건

- 감염성 검체가 Dry Zone 또는 농장환경으로 누출된 경우
- Blank에서 반복 신호가 발생해 Carry-over를 배제할 수 없는 경우
- 일회용 검체접촉부 분리가 실패해 다회용 내부 세척을 일상적으로 요구하는 경우
- 폐기물 보관·인계절차가 방역기관 요구를 충족하지 못하는 경우

## 13.4 오경보·위음성

### 1. 오류유형 분리

오경보와 위음성은 하나의 원인으로 취급하지 않는다.

| 오류유형 | 주요 원인 |
|---|---|
| 전처리 오류 | 시료량·희석·고형물·분주 실패 |
| 키트 오류 | 보관조건·Lot·유효기간·C선 실패 |
| 영상 오류 | 위치·초점·노출·번짐·판독시간 |
| 알고리즘 오류 | 잘못된 Threshold·Version·Calibration |
| 시계열 오류 | 기준선 오염·결측·계절변화 |
| 운영 오류 | 오장착·재검누락·경보 미확인 |
| 통신 오류 | 결과 전송지연·중복·누락 |
| 생물학적 위음성 | 낮은 항원량·비대표 시료·간헐배출 |

### 2. 결과상태와 기본대응

| 결과상태 | 의미 | 기본대응 |
|---|---|---|
| Negative | 키트에서 검출신호가 확인되지 않음 | 감염 부재로 확정하지 않고 계획된 감시 지속 |
| Positive | T선이 판독기준을 충족 | 동일 조건 재검·관리자 확인·공식검사 연결 검토 |
| Invalid | C선·분주·반응·촬영 등 품질조건 실패 | 원인코드 기록 후 재촬영 또는 재검 |
| Uncertain | 약한 신호·경계영역·판독불확실 | 자동재검과 관리자 검토 |
| Device Error | 장치·센서·통신 이상 | 검사결과와 분리하고 안전복귀·복구 |

검사결과와 Risk Level을 구분한다. Positive 한 번이 곧 ALERT 또는 확진을 의미하지 않으며, Negative 한 번이 NORMAL을 보증하지 않는다. 반복성·변화추세·QC·보조정보와 공식절차를 함께 고려한다.

### 3. 통제방안

- C선 유효성, ROI·초점·노출·위치·판독시간 QC
- Retake와 Retest를 구분
- Uncertain 상태를 억지로 양성·음성으로 강제하지 않음
- 동일 입력의 Risk Level·Reason Code 재현성 시험
- 모델·Threshold·Kit Profile 버전 고정과 변경승인
- 공식검사 Label 확보 전 복잡한 예측모델 적용 금지
- 농장·시간단위 데이터 누수를 막은 평가데이터 분리
- 농장·계절·축종·Kit Lot별 성능 모니터링
- 오경보 증가 시 임계값만 임의 상향하지 않고 원인분석
- 경보 후 사람의 확인과 전문기관 연결 유지
- 시스템만으로 이동제한·살처분 등 법정조치 자동결정 금지

### 4. 핵심 KPI

| KPI | 위험판단 |
|---|---|
| 위양성·위음성률 | 기준검사 Label 확보 후 계산 |
| Invalid·Uncertain 비율 | 품질·사용성 위험 |
| 재검 해소율 | 자동재검 유용성 |
| 정성판독 일치도 | 카메라 판독 정확성 |
| T/C 반복촬영 변동 | 시계열 활용 가능성 |
| 경보 확인률·확인시간 | 사용자 대응성 |
| 공식검사 연결시간 | 방역절차 연계성 |
| Risk Calibration | 등급별 실제 공식결과 대응 |
| 오경보당 추가비용 | 출동·검사·업무부담 |

### 5. 경보피로 관리

- 동일 원인의 반복경보를 묶어 표시
- 장치오류와 감염위험 경보의 시각·음향 구분
- 경보 우선순위와 Reason Code 제공
- 농장·지자체별 확인담당자와 대체연락자 지정
- 미확인 경보의 단계적 Escalation
- 경보 후 조치결과를 반드시 기록
- 월별 오경보·미확인·추가검사 비용 검토

### 6. 수정·중단조건

- 위음성 위험이 공식 방역절차에 잘못된 안도감을 주는 수준인 경우
- 오경보·Invalid가 현장출동과 사용자 업무를 방해하는 수준인 경우
- 자동재검이 일시적 오류와 반복 위험신호를 구분하지 못하는 경우
- 알고리즘 변경이 원자료·버전·성능 추적 없이 이루어지는 경우

## 13.5 농가 수용성

### 1. 주요 수용성 위험

- 계분벨트와 기존 작업동선 간섭
- 장치고장·누액·소독에 대한 불안
- 소모품 교체와 오류복구 업무 증가
- 잦은 경보와 공식검사 연결에 대한 부담
- 실증데이터가 행정처분·보상금 감액에 사용될 수 있다는 우려
- 농장 생산·출입·차량 데이터 공개에 대한 거부감
- 장치 설치로 방역취약 농장이라는 낙인이 생길 가능성
- 통신·앱·대시보드 사용의 어려움
- 장애 시 기업의 현장지원이 늦을 가능성
- 실증 종료 후 철거·데이터 보존·비용 부담 불명확

### 2. 대응원칙

1. 농장은 단순 시험장소가 아니라 현장 공동설계자와 사용자로 참여한다.
2. 설치 전 벨트·전원·통신·세척·폐기·작업동선을 조사한다.
3. 실증계약에 데이터 이용목적, 접근권한, 보존기간, 제공대상과 파기방법을 명시한다.
4. 실증데이터의 행정·보험·계약상 이용범위는 지자체·농장·전문기관과 사전합의한다.
5. 농가 화면에는 확진표현보다 위험단계·이유·재검상태·권고조치를 제공한다.
6. 교육은 설치 시 1회가 아니라 정기·교대인력·사고대응 교육으로 운영한다.
7. 통신두절 시 로컬검사·저장과 복구 후 동기화를 지원한다.
8. 장애신고 채널, 응답시간, 현장출동과 예비장치 기준을 SLA에 포함한다.
9. 참여중단·장치철거·데이터반환 조건을 계약에 포함한다.
10. 농가 신고와 기존 임상예찰을 장치결과보다 후순위로 두지 않는다.

### 3. 역할과 책임

| 주체 | 책임 |
|---|---|
| 농장 관리자 | 장치상태 확인, 소모품 교체, 경보확인, 의심상황 신고 |
| 개발기업 | 설치·교육·원격점검·장애복구·데이터품질 |
| 지자체 | 참여농가 선정, 사업운영, 경보대응 담당자 지정 |
| 전문기관 | 공식검사, 시료안전, 결과비교와 전문자문 |
| 키트·제조 파트너 | IFU·Lot·품질·공급·불량대응 |
| 계열화사업자 | 허용된 범위의 농가운영 지원과 데이터책임 |

### 4. 수용성 KPI

|---|---|

### 13.6.2 키트·소모품·공급망 위험

제3자 AIV 키트는 실비성 조달항목이며 회사 핵심마진과 분리한다. 그러나 키트 공급중단이나 Lot 편차는 전체 서비스 운영을 멈출 수 있으므로 핵심 공급망 위험으로 관리한다.

- 제조사·국내 공급사의 공식 견적과 공급기간 확보
- 키트 IFU, 보관온도, 유효기간, 허용검체 문서 보존
- Kit Type·Lot·유효기간·입출고·사용장치 추적
- 60·100·150회 검사량 시나리오별 분할조달
- 무효·재검률과 납기를 반영한 안전재고
- 선입선출과 유효기간 임박재고 경보
- Lot 변경 시 수동·자동 판독과 기준시료 비교
- 대체 키트는 Kit Profile만 바꾸어 즉시 사용하지 않고 호환성·성능·규제 재검토
- Composite Cartridge OEM 금형·품질·최소주문량과 이원화 검토
- 불량 Lot 격리·회수·교체와 영향받은 검사이력 추적

### 13.6.3 데이터·사이버보안 위험

농장 장치는 물리동작과 검사데이터를 함께 다루는 IoT 제품이므로 일반 웹서비스보다 장치·계정·업데이트·원격제어 위험을 함께 관리한다. NIST IoT 보안기준의 장치식별, 설정관리, 데이터보호, 인터페이스 접근통제, 안전한 업데이트와 보안상태 인지를 기본 참고체계로 사용한다.

| 보안영역 | 기본통제 |
|---|---|
| 장치식별 | Device ID·Serial·인증서, 위조장치 차단 |
| 계정·권한 | 역할기반 최소권한, MFA 후보, 퇴직·변경 즉시회수 |
| 데이터보호 | 전송·저장 암호화, 비밀정보 분리 |
| 인터페이스 | 불필요 Port·서비스 차단, 원격접속 제한 |
| 업데이트 | 서명된 Firmware·Software, Version·Rollback |
| 감사 | 로그인·설정·경보·다운로드·삭제 로그 |
| 무결성 | 원자료 Hash·버전·시간정보, 임의수정 방지 |
| 가용성 | Edge 저장, Backup·Restore, 장애복구시험 |
| 취약점 | 제보채널, Patch 정책, 지원종료 계획 |
| 사고대응 | 계정차단·장치격리·영향분석·통지 절차 |

농장·차량·방문관계 데이터는 역학적으로 민감할 수 있다. 수집 최소화, 목적 제한, 접근승인, 보존기간, 다운로드 통제와 계약 종료 후 파기절차를 적용한다. 공식 데이터 연계 권한이 없으면 Mock 또는 협력농장 자체 허용데이터로만 구조를 검증한다.

### 13.6.4 규제·품질·제품책임 위험

“확진장비가 아니다”라는 문구만으로 규제대상이 아니라고 가정하지 않는다. 사용목적, 자동 전처리, 상용키트 결합, 판독 소프트웨어와 경보서비스를 기준으로 다음을 사전검토한다.

- 동물용의료기기 또는 동물용체외진단의료기기 해당 여부
- 제조업허가·품목허가·신고 필요 여부
- 연구시험용과 판매용 장치의 구분
- 키트 허용검체에 분변·Composite Sample이 포함되는지
- 자체 희석·침전·상층액 사용이 허가범위에 부합하는지
- 키트 제조사와 자동화 결합에 대한 기술·계약상 허용범위
- OEM 제조자·품목허가자·판매자·운영자의 책임
- 알고리즘·Threshold·Kit Profile 변경관리
- 일회용 Cartridge의 원재료·Lot·출하검사
- 사용자 설명서·금기·경고·잔여위험 표시
- A/S·하자보수·리콜·제품책임보험
- 경보 누락·오경보·데이터장애의 계약상 책임한계

규제분류와 허가전략은 농림축산검역본부 등 관계기관의 사전상담과 전문 자문을 거쳐 확정한다.

| 위험 | 대응 |

| Cartridge 원가상승 | 소량생산·MOQ 부담 | 설계단순화·OEM 복수견적 |

원가는 시제품·소량생산·양산 단계별 견적과 실제 장애·재검·현장출동 자료로 갱신한다. 공공고객의 지불의사를 초과하면 기능·검사량·서비스수준을 조정하고, 조정 후에도 경제성이 성립하지 않으면 확대를 중단한다.

### 13.6.7 공모전 이후 해소할 잔여불확실성

공모전 단계에서 확인할 수 없는 항목은 위험등록부에 공개하고 다음 Gate의 필수 산출물로 전환한다.

| 잔여불확실성 | 해소방법 | 완료 Gate | 미해소 시 결정 |
|---|---|---|---|
| 키트 허용검체·자동화 결합 | IFU·제조사·규제기관 검토 | Gate 0 | 키트·전처리·사용목적 변경 |
| 실제 분변 회수율·방해 | 전문기관 Matrix 시험 | Gate 4 | 제품역할 축소 |
| 장치·카트리지 원가 | 복수 BOM·OEM 견적 | Gate 1~2 | 설계·가격·수량 수정 |
| 고객 지불의사 | 농가·지자체 인터뷰와 유료실증 | Gate 5~6 | 구매자·계약모델 변경 |
| 제품분류·허가범위 | 검역본부 사전상담·서면자료 | Gate 0 | 판매·실증일정 조정 |
| 경쟁제품·특허 중첩 | 실명 Benchmark·청구항·FTO 검토 | Gate 1 | 회피설계·기능범위 수정 |
| 공공조달 적합성 | 수요기관·조달담당자 검토 | Gate 6 | 다른 적법한 계약경로 적용 |

불확실성을 공모전용 가정으로 덮지 않는다. 다만 공모전 이후에도 반복해서 필요한 자료를 확보하지 못하거나 사업성·안전성·규제 적합성이 성립하지 않으면 확대를 중단하거나 제품역할을 축소한다.

## 13.7 대응전략

### 1. Risk Register 운영

모든 핵심위험은 문서의 설명으로 끝내지 않고 Risk Register로 관리한다.

| 필드 | 기록내용 |
|---|---|
| Risk ID | 위험 고유번호 |
| 위험사건 | 발생할 수 있는 구체적 사건 |
| 원인 | 생물학·기계·사람·공급·제도 원인 |
| 영향 | 방역·안전·성능·비용·일정·법적 영향 |
| 초기등급 | 통제 전 Critical·High·Medium·Low |
| 예방통제 | 설계·절차·계약·교육 통제 |
| 탐지방법 | Sensor·QC·KPI·감사·시험 |
| 비상대응 | 발생 후 격리·복구·통지 |
| 책임자 | 개발·농장·지자체·전문기관·공급사 |
| 완료기한 | Gate와 연결된 조치기한 |
| 잔여위험 | 통제 검증 후 남은 위험 |
| 결정 | 수용·추가완화·연기·중단 |
| 근거 | 시험보고서·회의록·승인·Version |

Critical 위험은 개발기업 단독 판단으로 수용하지 않는다. 전문기관·수요기관·안전책임자의 검토가 필요한 위험은 승인주체와 근거를 기록한다.

### 2. Gate별 위험검토

| Gate | 필수 위험검토 |
|---|---|
| Gate 0 | 사용목적, 규제분류, 허용검체, 생물안전, 책임구조 |
| Gate 1 | 혼합·침전·분주·카메라·오류상태와 Mock 안전성 |
| Gate 2 | Sampling 대표성 후보, 벨트간섭, 안전복귀, 누액 |
| Gate 3 | 정상농장 내구성, 관리자 개입, 통신·환경·폐기 |
| Gate 4 | 기준검사 비교, 위양성·위음성, Carry-over, Kit Lot |
| Gate 5 | 오경보·경보피로, 공식검사 연결, 농가 수용성 |
| Gate 6 | 규격·품질·SLA·보험·원가·공공조달 |
| Gate 7 | 10개 농가 공급망·관제·재계약·데이터 책임 |
| Gate 8 | 지역별 재현성, 보안감사, 확장원가, 타 질병 재검증 |

각 Gate 종료 시 신규위험, 통제완료, 시험실패, 잔여위험과 다음 단계 조건을 함께 승인한다. 일정 준수를 이유로 Critical 위험을 다음 단계로 이월하지 않는다.

### 3. 사고등급과 대응

| 사고등급 | 예시 | 즉시조치 |
|---|---|---|
| Level 1 운영이상 | 단일 Invalid, 일시 통신지연 | 자동재시도·기록·모니터링 |
| Level 2 중대운영 | 반복막힘, 장치중단, Lot 이상 | 해당 장치·Lot 격리, 원인분석 |
| Level 3 방역·안전 | 검체누출, 교차오염 의심, 경보누락 | 검사중지, 현장격리, 책임자·기관 보고 |
| Level 4 보안·제도 | 데이터유출, 비인가 원격제어, 무허가 판매위험 | 서비스격리, 접근차단, 법무·기관 대응 |

구체적인 보고대상과 시간은 관련 법령·기관절차·실증계약에 따른다. 사고를 숨기거나 실패·Invalid 데이터를 삭제하지 않으며, 영향받은 장치·농장·시료·키트 Lot과 소프트웨어 버전을 추적한다.

### 4. 일정 변경·중단조건

다음 상황에서는 계획된 날짜를 맞추기 위해 다음 단계로 강행하지 않는다.

#### 기술·생물안전

- 반복 Sampling이 계분배출을 방해하거나 안전복귀가 불안정
- Composite Sample 변동이 커 비교 가능한 데이터 생성 불가
- 분변 방해요인과 고형물 문제를 제어하지 못함
- 자동분주·카메라 판독 반복성이 현장목적에 부적합
- 교차오염·누액·폐기물 위험을 통제하기 어려움

#### 진단·실증

- 키트 허용검체와 장치 전처리가 부합하지 않음
- 실제 분변에서 항원신호가 지나치게 불안정
- 자동재검·시계열 분석이 우선순위 판단에 추가정보를 제공하지 못함
- 공식검사보다 의미 있는 선행정보를 확보하지 못함
- 오경보·위음성·Invalid가 방역 또는 현장운영을 방해
- 전문기관 기준검사 비교자료를 확보할 수 없음

#### 사업·제도

- 규제·허가경로가 사업비와 기간에 부합하지 않음
- 전문기관·농장·지자체 협력구조 미확보
- 데이터 이용권한·책임범위 합의 실패
- 소모품·유지관리비가 공공고객 지불의사 초과
- 유료실증·후속구매·재계약으로 전환되지 않음
- 제품책임·보험·품질보증 체계를 확보하지 못함

### 5. 제품역할 조정 시나리오

핵심 가설의 일부가 성립하지 않더라도 검증된 기능을 별도 제품역할로 전환할 수 있다.

| 실패한 가설 | 조정 가능한 역할 |
|---|---|
| 분변 신속항원 조기탐지 성능 부족 | 자동 시료관리·검사기록 장치 |
| 시계열 위험예측의 추가효과 부족 | 신속키트 자동판독·품질관리 장치 |
| 공식검사 선행시간 부족 | 재검 우선순위·장치상태 관리 플랫폼 |
| 공공 실시간 경보 활용성 부족 | 전문기관 연구·실증 데이터 수집장치 |
| 단일지점 대표성 부족 | 기본장치 안정화 후 Multi-point 별도검증 |
| 공식 이동데이터 연계 불가 | 허가된 자체·Mock 데이터 기반 연구기능 |
| 전국확산 경제성 부족 | 충북 지역밀집 운영모델에 집중 |

역할을 변경할 때 사용목적, 성능주장, 계약가격, 규제분류와 사용자 설명서를 함께 수정한다. 기존 성능자료를 새로운 제품역할의 근거로 자동 전용하지 않는다.

### 6. 책임주체

| 위험관리 업무 | 주관 | 협조·승인 |
|---|---|---|

## 13장 종합 위험관리 원칙

본 사업은 신속항원키트의 한계, 분변시료의 변동, 단일 Sampling Point의 대표성, 교차오염, 경보오류와 현장 운영부담을 숨기지 않는다. 장치·알고리즘·농장·전문기관·공공계약을 하나의 운영체계로 보고, 각 Gate에서 위험통제의 실제 효과를 시험한다.

> **Negative는 감염 부재를 확정하지 않고, Positive는 확진을 의미하지 않으며, Invalid·Uncertain·실패데이터를 삭제하지 않는다. 검증되지 않은 위험은 다음 Gate로 넘기지 않고, 핵심 가설이 실패하면 일정과 제품역할을 조정한다.**
